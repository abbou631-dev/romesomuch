# Prototype

The single-file design prototype the Astro site was built from, kept for reference.

- `design-prototype.html` — the whole site in one file: hash router, experiences as a JS array,
  images inlined as data URIs. Open it in a browser, no build step. This is the design source of
  truth for anything the Astro components do not yet cover.
- `handoff.html` — the handoff document: decisions, constraints and what is still missing.

Both are frozen. Changes belong in `src/` at the repo root.
